# CaesarCipher - шифр Цезаря на Java

Финальный проект для 1 Модуля «Java Syntax» для курса JavaRush. 
Реализует шифрование и дешифрование текста с помощью шифра Цезаря, а также методы автоматического подбора ключа.

## Функционал

- Шифрование текста из файла с заданным ключом.
- Дешифрование текста при известном ключе.
- Brute‑force: перебор всех возможных ключей и выбор наиболее «читаемого» варианта с помощью эвристики.
- Валидация входных данных (существование файлов, корректность ключа и режима).
- Поддержка больших текстовых файлов (буферизованное чтение).

## Стек

- Java 8+
- Стандартная библиотека Java (java.nio.file, java.util)
- Без сторонних зависимостей

## Требования

- JDK 8 или выше
- Кодировка файлов: UTF‑8

## Как запустить

1. Скомпилируйте проект любым удобным способом (Maven, Gradle, javac).
2. Запустите главный класс: `java App`.
3. Следуйте инструкциям в консольном меню:
   - 1 - шифрование
   - 2 - дешифрование с известным ключом
   - 3 - brute‑force (подбор ключа)

## Особенности реализации

- Алфавит: русский алфавит + базовые знаки препинания и пробел.
- Регистр текста нормализуется к нижнему.
- Символы, отсутствующие в алфавите, остаются без изменений.
- Оценка «читаемости» текста - эвристическая (частота пробелов, знаков, частых биграмм). Не гарантирует 100% точность, особенно на коротких текстах.
